## What the UI tests exercise (driven only through `XCUIRemote`: up/down/left/right/select/menu)

- First launch, onboarding, baseline game, skip path, Home.
- A full lesson session, feedback, summary, sticker book.
- Focus-only navigation of every screen, no focus traps, Menu/Back behaviour, focus restored to the opener after leaving a parent page.
- Parent gate (hold step, adult challenge, lockout, "I can't hold" route, Menu leaves), parent pages, settings, data deletion.
- Reduce Motion launch, disabled audio, accessibility identifiers/labels present on key controls.
- Persistence across terminate and relaunch.

## What is NOT covered by these results

- Real Apple TV hardware or a physical Siri Remote (the real long-press gesture feel, overscan, HDR/colour).
- Real VoiceOver speech and reading order; only metadata (labels, identifiers, traits) is asserted.
- Visual review: no screenshots were inspected, so layout polish, contrast and legibility at 10 ft are unverified. Only the default simulator resolution was run.
- Audio: every sound is a placeholder; interruption handling is unit-tested at the controller level, not with real phone-call or Siri interruptions.
- iCloud backup (needs a signed build with the capability).
- Household profiles via `TVUserManager` (not implemented; see REMAINING_WORK.md).
- Curriculum sequence is inferred from public descriptions of systematic synthetic phonics; it has not been checked against, and does not claim to match, any published programme.
